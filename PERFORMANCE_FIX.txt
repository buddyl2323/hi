- Removed intentional 15/25/30 FPS throttling; rendering now targets up to 60 FPS (device-dependent).

- Reduced expensive wave drawing and island foliage on Medium/High.
- Reduced unnecessary canvas clear operations and HUD refresh frequency.
- Multiplayer polls every 1.2 seconds rather than 0.85 seconds; smoothed remote boats without offscreen snap.
- Preserved existing game features and server code.
